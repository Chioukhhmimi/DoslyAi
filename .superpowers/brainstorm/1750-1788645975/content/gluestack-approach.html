C — Swap Engine, Keep Look

Rebuild each existing custom component (Button, SelectableChip, etc.) using Gluestack primitives internally — same visual output, better engine. No visual change for users.

Pros

  • Zero visual regression
  • Gain Gluestack benefits
  • Clean component API

Cons

  • Non-trivial per-component work
  • Need to match pixel-exact
  • Still need NativeWind setup

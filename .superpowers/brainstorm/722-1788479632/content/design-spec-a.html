5 · What changes in the codebase

  • constants/colors.ts — primary* + surface/text tokens rewritten. Everything using Colors.* cascades automatically.
  • constants/spacing.ts — Radius.xs/sm/md/lg/xl values bumped. All borderRadius calls cascade automatically.
  • constants/shadows.ts — shadowColor updated to #1C1917. All Card/sheet shadows cascade.
  • EmptyIllustrations.tsx — uses Colors.primary* directly, auto-updates to teal.
  • constants/colors.ts — supplement token — currently #059669 (dark green). With teal primary, supplement needs to shift to avoid collision: → #16A34A (green-600, more saturated).

No component files touched. The entire design shift lives in 3 constant files. All 14 components and 19 screens update automatically through the token system.
